# Resource-pegged stablecoin project

<https://gov.gitcoin.co/t/resource-pegged-stablecoin-project/21660>
tobiasocula | 2025-07-08 11:07:41 UTC | #1

Hi all,
I've recently researched and developed a new idea for a custom stablecoin project.
The idea is simple: to create a stablecoin whose value is pegged to an index of basic human resources like water, electricity and food nutrients.
The goal is to maintain the value of this token in the long term and make it so that it grants the user the same purchasing power over time. I explicitly designed the token to be completely independent on any fiat currencies.
I thought to reach out to the Gitcoin community because I believe the goal of this token aligns with the values of the Gitcoin vision.
The Github repo is private for now, simply because I'm still looking for any potential partnership or feedback, but if anyone in the Gitcoin team is interested, I'd love to work together and gather feedback for the project.
Thank you for reading!
Regards, Tobias
For anyone interested in further contact, just email me at tobias.ocula@outlook.com or contact me at https://www.linkedin.com/in/tobias-ocula-424aa6359/ :)
