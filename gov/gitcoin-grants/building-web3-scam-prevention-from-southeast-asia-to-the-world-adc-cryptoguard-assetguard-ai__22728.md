# ⚡ Building Web3 Scam Prevention From Southeast Asia to the World – ADC CryptoGuard & AssetGuard + AI

<https://gov.gitcoin.co/t/building-web3-scam-prevention-from-southeast-asia-to-the-world-adc-cryptoguard-assetguard-ai/22728>
ADCoinX | 2025-08-25 00:22:51 UTC | #1

Hi everyone 👋

I’m **Muhammad Yusri Adib**, a solo builder from Malaysia under ADCX Lab. I’ve been experimenting with lightweight Web3 safety tools to explore how scam prevention could be improved for new users, especially in Southeast Asia where many first-time users face losses early on.

One approach I’m testing is a validator that flags risky wallets/tokens, provides AI-driven risk scoring, and exports results in ISO 20022 XML format for compliance use.

Demo links (for reference only, if anyone’s curious):
🔗 Wallet Validator – https://adcoin-validator-ai.onrender.com
🔗 Asset Validator – https://adc-assetguard-ai.onrender.com

I’d really value the community’s perspective — what do you think is the biggest challenge for Web3 scam prevention: technical accuracy, adoption, or building user trust?
